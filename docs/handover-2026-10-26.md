## Replaying the sub-analysts
The B11 replays used throwaway scripts in the session scratchpad, which won't survive. To rebuild one:
1. Call `smartops.main._load_env_file()`.
2. Load a saved task's `findings.json`.
3. Run the blind sub-analysts over it.
4. Read `findings.findings`, not `.records`. Dump the result to JSON before reading any fields, so a wrong field doesn't cost a paid run.
