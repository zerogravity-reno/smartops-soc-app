## How the loop works now

```
Analyst (Foundation-Sec, webapp/main.py _run_investigation)
  plan: hypotheses + tasks {task_id, question, entity, time_window}
      │  run_trace.to_task_file()  →  .smartops/runs/<run_id>/tasks-L<n>.json
      ▼
Tool Broker (python -m smartops.main --task-file … --batch-id <run_id>-L<n>)
  per task: plan_fetch → siem/vt subagents (official Splunk MCP) → 3 sub-analysts
      │  writes .smartops/runs/<task_id>/<stamp>/{report,evidence,findings}.json
      │  and   .smartops/runs/<run_id>-L<n>/analyst-payload.json
      ▼
Analyst synthesis reads the payload → scores → follow_up_tasks → next loop
```

Everything is joined by the webapp's `run_id`. The trace for one investigation is `.smartops/runs/<run_id>/investigation.jsonl`, with one line per step:
- `analyst_plan`
- `broker` (task file, what was dropped, exit code, log, each task's `run_dir` and `trace_id`, the handshake)
- `synthesis`

Engine output for each loop is in `broker-L<n>.log` beside it.

```powershell
uv sync                                   # installs webapp + engine + contracts + dev tools
uv run pytest -q                          # 1123 passed
.\start.ps1                               # or start_server.bat; UI on http://localhost:8001
```

Broker only, without the UI:

```powershell
uv run python -m smartops.main --task-file docs\examples\botsv3-coinhive-tasks.json --batch-id demo-L2
```

Add `--scripted` for no model calls.

**Caution:** blanking `SMARTOPS_LLM_PROVIDER` does **not** stop Broker model calls, because the engine still finds a model from the other AWS settings. Only `--scripted` is guaranteed free. A streaming check on 2026-09-30 spent $0.06 because of this.
