## How to check a fix live
- Re-run a saved round through the Broker CLI:
  `uv run python -m smartops.main --task-file .smartops/runs/<run>/L<n>/tasks.json [--task-id <id>] --batch-id <name>`.
  It uses live Splunk and costs real money: about $1.6 for the Broker plus $0.6 for the sub-analysts on a 5-task round.
- Each task's output is at `.smartops/runs/<task_id>/<timestamp>/report.json`: `step_outcomes`, and `results[].queries_run`/`findings`. The batch payload is at `.smartops/runs/<batch-id>/analyst-payload.json`.
- To replay packing offline, run `pack_for_analyst` over the saved `L<n>/T*/findings.json` with `HANDOFF_CHAR_BUDGET`.
