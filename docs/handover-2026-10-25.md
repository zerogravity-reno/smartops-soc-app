## How to check a fix live
- **Broker only:** re-run a saved round through the CLI:
  `uv run python -m smartops.main --task-file .smartops/runs/<run>/L<n>/tasks.json [--task-id <id>] --batch-id <name>`.
  It uses live Splunk and costs real money: about $1.6 for the Broker plus $0.6 for the sub-analysts on a 5-task round.
- **Full app (Analyst plus Broker, multi-round):**
  1. Start the server: `uv run uvicorn smartops.main:app --host 127.0.0.1 --port 8013`.
  2. `POST /api/run` with `{"context_contract": <the "context" of a saved run's first investigation.jsonl line>}`.
  3. Read `GET /api/run/stream/<run_id>` until `done`.
  The run lands in `.smartops/runs/<run_id>/`.
- **Outputs:** each task's output is at `.smartops/runs/<run>/L<n>/T<k>/report.json` (or `.smartops/runs/<task_id>/<timestamp>/` for CLI runs). Look at `step_outcomes` and `results[].queries_run`/`findings`.
- **Offline packing replay:** run `pack_for_analyst` over the saved `L<n>/T*/findings.json` with `HANDOFF_CHAR_BUDGET`.
