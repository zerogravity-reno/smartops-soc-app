## What changed today (approved plan: `~/.claude/plans/witty-bouncing-toucan.md`)
1. **F1, spend.**
   - `Budget.spend_for_task(task_id)` sums the task's own spend and every mission under it.
   - It is used by `broker.py` (the report's `total_spend_micro_usd`) and by `main.py` (the log's `this task`). `main._task_spend` is deleted.
   - The test now charges a subagent's spend.
2. **F3, runaway replies.**
   - `_invoke_with_one_reask` treats `stop_reason == "length"` as a parse failure and re-asks once: "you hit the token limit, do not repeat citations".
   - This covers T1's ", , , , had no matching events" loop. It is shared with the shown arm.
3. **F5, duplicate sets.**
   - `route()` sends identical non-empty rows only once per category and logs the skipped query.
   - Empty sets are all kept.
4. **F2, command block and budget.**
   - The command lines are a narrative footer again (`COMMANDS_FOOTER`, after `ENCODED_FOOTER`), because narratives always cross.
   - `pack_for_analyst`: when the fixed part overflows, observations are cut from the tail of the largest domain, with "… N observations omitted". It reserves room for each domain's summary-omission note.
5. **F4, narrative figures.**
   - `_drop_unsupported_sentences` drops a sentence stating a multi-digit figure or a clock time found in no block the analyst read, and logs it in full.
   - It started out checking summaries only; that dropped a true sentence citing event codes 4624/4672, so it now checks the full block text, the same rule as `_drop_unsupported_figures`.
   - Known gaps: spelled-out counts ("twice"), and a figure that happens to appear elsewhere in the rows.
